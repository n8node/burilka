# Персонажи (GLB)

14 рабочих + проп-планшет. Метры, Y вверх, персонаж стоит в начале координат лицом к +Z, ступни на Y=0, рост ~1,85 м.
Нейтральная поза (руки вдоль тела), анимаций и скиннинга нет.

Персонаж — иерархия жёстких частей. Суставы — именованные узлы, вращая их, можно позировать и анимировать:
pelvis → hip_L/R → knee_L/R → ankle_L/R
pelvis → spine → chest → shoulder_L/R → elbow_L/R → wrist_L/R
chest → neck → head
_L/_R — левая/правая сторона самого персонажа.

Планшет: props/tablet.glb, в сцене крепится к wrist_L.
