# GLB-модели агрегатов из 3D-сцены кустовой площадки

- `01_classic_rig/` — классическая БУ (34 агрегата)
- `02_robotic_rig/` — роботизированная БУ (38 агрегатов, включая роботов пола буровой)
- `03_camp/` — жилой городок (7 объектов)
- Траектории скважин (`trajectory`) и цементировочный флот (`cementFleet`) лежат в `01_classic_rig/`
- `index.csv` — соответствие файлов и русских названий; `_preview.png` — превью всех моделей

Координаты: метры, Y вверх. Каждый агрегат сохранён в системе координат своей установки
(начало — ось скважины), поэтому файлы одной БУ при импорте встают на свои места без подгонки.
Материалы — PBR (metalness/roughness), анимаций нет: геометрия зафиксирована в стартовом состоянии сцены.
